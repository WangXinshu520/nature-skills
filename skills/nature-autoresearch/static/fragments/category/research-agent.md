# Research-Agent Systems / 科研智能体系统

全流程科研自动化系统。覆盖 idea 生成 → 文献综述 → 实验 → 论文写作 → 审稿的完整科研生命周期。

For full descriptions, see `references/full-catalog.md`.

## 工具列表 / Tool List

- [aiming-lab/AutoResearchClaw](https://github.com/aiming-lab/AutoResearchClaw) — 端到端研究流程：话题→文献综述→实验→分析→审稿→论文初稿 (End-to-end pipeline from topic to paper draft)
- [OpenRaiser/NanoResearch](https://github.com/OpenRaiser/NanoResearch) — 端到端自主研究引擎，本地/SLURM运行、分析真实结果、基于输出写论文 (End-to-end engine with local/SLURM execution and grounded paper writing)
- [kaust-ark/ARK](https://github.com/kaust-ark/ARK) — idea+venue→paper，6智能体编排，CLI/Web/Telegram控制 (6-agent orchestration with CLI, web dashboard, Telegram control)
- [wanshuiyin/Auto-claude-code-research-in-sleep](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep) — Markdown-first研究流程，文献综述+实验+论文迭代+跨模型批评 (Markdown-first workflows with cross-model critique)
- [skyllwt/AutoSci](https://github.com/skyllwt/AutoSci) — Wiki-centric全生命周期研究平台，20+技能覆盖完整循环 (Wiki-centric platform with 20+ skills covering full research loop)
- [Sibyl-Research-Team/AutoResearch-SibylSystem](https://github.com/Sibyl-Research-Team/AutoResearch-SibylSystem) — 全自主AI科学家，多智能体研究迭代+GPU实验+自进化外环 (Fully autonomous with multi-agent iteration and self-evolving outer loop)
- [eimenhmdt/autoresearcher](https://github.com/eimenhmdt/autoresearcher) — 早期开源科学工作流自动化包，当前聚焦文献综述生成 (Early open-source package for scientific workflow automation)
- [hyperspaceai/agi](https://github.com/hyperspaceai/agi) — 分布式P2P研究网络，自主agent运行实验、gossip发现、CRDT排行榜 (Distributed P2P network with CRDT leaderboards)
- [Human-Agent-Society/CORAL](https://github.com/Human-Agent-Society/CORAL) — 自主多智能体进化，共享持久记忆、异步执行、心跳干预 (Long-running agents with shared persistent memory, SOTA on 10 tasks)
- [SakanaAI/AI-Scientist](https://github.com/SakanaAI/AI-Scientist) — 首个全面自动化科学发现系统 (First comprehensive fully automatic scientific discovery system)
- [SakanaAI/AI-Scientist-v2](https://github.com/SakanaAI/AI-Scientist-v2) — Workshop级自动科学发现，移除模板依赖、推广到多个研究领域 (Template-free agentic tree search across research domains)
- [AweAI-Team/AiScientist](https://github.com/AweAI-Team/AiScientist) — 长时域ML研究实验室，层级编排+File-as-Bus协调，驱动PaperBench/MLE-Bench (Long-horizon with hierarchical orchestration and File-as-Bus coordination)
- [HKUDS/AI-Researcher](https://github.com/HKUDS/AI-Researcher) — NeurIPS 2025，完整端到端研究自动化：假设→实验→稿件→审稿 (NeurIPS 2025, full end-to-end with production version at novix.science)
- [openags/Auto-Research](https://github.com/openags/Auto-Research) — OpenAGS，全研究生命周期的AI智能体团队编排 (Agent team orchestration across full research lifecycle)
- [SamuelSchmidgall/AgentLaboratory](https://github.com/SamuelSchmidgall/AgentLaboratory) — 端到端自主研究流程：idea→文献综述→实验→报告，支持自主/副驾模式 (End-to-end with autonomous and co-pilot modes)
- [AgentRxiv](https://agentrxiv.github.io/) — 协作自主研究框架，智能体实验室共享预印本服务器 (Collaborative framework sharing preprint server across agent labs)
- [JinheonBaek/ResearchAgent](https://github.com/JinheonBaek/ResearchAgent) — 基于科学文献的迭代研究idea生成，多智能体审稿反馈 (Iterative idea generation over scientific literature)
- [du-nlp-lab/MLR-Copilot](https://github.com/du-nlp-lab/MLR-Copilot) — 自主ML研究框架，生成idea→实现实验→分析结果 (Autonomous ML research: ideas, experiments, analysis)
- [MASWorks/ML-Agent](https://github.com/MASWorks/ML-Agent) — 强化LLM智能体进行自主ML工程，试错中学习 (Reinforcing LLM agents through trial and error)
- [PouriaRouzrokh/LatteReview](https://github.com/PouriaRouzrokh/LatteReview) — 低代码Python包，AI驱动的自动化系统文献综述 (Low-code automated systematic literature reviews)
- [LitLLM/LitLLM](https://github.com/LitLLM/LitLLM) — AI驱动的文献综述助手，RAG生成准确的相关工作章节 (RAG-powered literature review for related-work sections)
- [Agent Laboratory](https://agentlaboratory.github.io/) — 三阶段研究流程：文献综述→实验→报告撰写 (Three-phase pipeline: Literature Review → Experimentation → Report Writing)
